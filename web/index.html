TwiPla画像

TwiPlaの画像アップロードの代わりに、外部の画像サービスImgBBを使います。選んだ画像をImgBBへ直接送り、その画像URLをTwiPlaの本文に挿入します。

1. APIキーを入力する

または、自分でAPIキーを取得する
  1. ImgBBのAPIページを開きます。
  2. ImgBBにログインしてAPIキーを取得し、このページに戻ります。
  3. 取得したキーを上の入力欄に貼り付けます。

2. ブックマークに登録する

TwiPla画像

スマートフォンでは、このページを一度ブックマークに追加し、そのURLを登録用コードに置き換えます。ホーム画面への追加では実行できません。

iPhone・iPadのSafari
  1. 「登録用コードをコピー」をタップします。
  2. Safariの共有メニューから「ブックマークを追加」を選び、名前を「TwiPla画像」にして保存します。
  3. Safariのブックマーク一覧を開き、保存した「TwiPla画像」を長押しして「編集」を選びます。
  4. URL欄の内容をすべて消して、コピーしたコードを貼り付けます。先頭がjavascript:であることを確認して保存します。
  5. 同じSafariでTwiPlaのイベント作成・編集画面を開きます。ブックマーク一覧から「TwiPla画像」をタップして実行します。
Appleのブックマーク操作案内
AndroidのChrome
  1. 「登録用コードをコピー」をタップします。
  2. Chromeのメニュー「︙」から星印をタップし、このページをブックマークに追加します。
  3. 「︙」→「ブックマーク」を開き、追加した項目のメニューから「編集」を選びます。
  4. 名前を「TwiPla画像」にし、URLをすべて消してコードを貼り付け、保存します。先頭がjavascript:であることを確認してください。
  5. 同じChromeでTwiPlaのイベント作成・編集画面を開き、アドレス欄に「TwiPla画像」と入力します。
  6. 候補に出たブックマーク「TwiPla画像」をタップします。検索ボタンを押したり、ブックマーク一覧から開いたりせず、アドレス欄の候補から選びます。
Chrome開発者による実行手順
iPhoneのChrome
  1. コードをコピーし、Chromeのメニュー「…」からこのページをブックマークに追加します。
  2. ブックマークの「編集」を開き、名前を「TwiPla画像」にして、URL全体をコードに置き換えます。先頭のjavascript:を確認して保存します。
  3. TwiPlaのイベント作成・編集画面を開き、アドレス欄に「TwiPla画像」と入力して、候補のブックマークを選びます。

実機での動作は未確認です。実行できない場合はSafariで登録してください。

AndroidのSamsung Internet・Firefox・Edge

これらのブラウザで、このブックマークレットが動作するかは確認できていません。AndroidではChromeの登録手順をご案内しています。

Samsungのブックマーク操作案内・Firefoxのブックマーク操作案内

パソコンのChrome・Safari・Firefox・Edge
  1. ブラウザのブックマークバーを表示します。
  2. 上の「TwiPla画像」リンクを、ブックマークバーへドラッグします。
  3. TwiPlaのイベント作成・編集画面で、登録した「TwiPla画像」をクリックします。

3. TwiPlaに画像を挿入する

  1. 登録に使ったブラウザで、TwiPlaのイベント作成・編集画面を開きます。
  2. 登録した「TwiPla画像」を実行します。
  3. 本文の挿入したい場所をタップしてから、パネルの「画像を選択」で画像を選びます。複数選択もできます。
  4. アップロードが終わったら本文を確認し、TwiPlaの保存ボタンで保存します。

JPEG・PNG・GIF・WebP・HEIC・HEIFの32MB以下の画像に対応します。

画像はImgBBに保存されます。画像URLを知っている人は画像を見ることができます。「管理データを保存」で削除用URLを手元に残せます。TwiPlaの本文から画像を消しても、ImgBBの画像は削除されません。

実行できないとき

  • ブックマークのURLがjavascript:で始まっているか、途中で切れていないか確認してください。
  • 通常のページが開く場合は、保存したURLを登録用コードに置き換えてください。
  • APIキーを変更した場合は、コードを作り直してブックマークのURLも置き換えてください。
  • ブラウザの制限やTwiPla側の変更で実行できない場合があります。
